# [READY] System — The pages (what she knows about Dana)
> Signed by LO 2026-09-29, the day it was drafted — LO bypassed the day-after rule for this test.

**What it tracks:** how many of Dana's diary pages she has heard. **Kind:** sourced — only the
library fills it; half the game reads it. **The number:** `kessler_stage`, 0–5 — page *n* read means
the stage is *n*.

## Where it is filled

| where | the row | effect |
|---|---|---|
| Library | Kessler, pages one to four (his steps 1–4) | `kessler_stage` set to the step number |

One page a night: the step sets `read_for_kessler_today`, cleared overnight.

**Brake:** one page a night, and each page is one step on Kessler's ladder.
