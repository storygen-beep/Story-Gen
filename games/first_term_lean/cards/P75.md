How it works (engine, read):
  - Every render of a place rolls its random canvases again, so coming back from an action is a new roll:
    setup.getStoryCanvasRedirect falls through to setup.checkRandomEncounters (v2.py:6599-6612), called from every
    location passage (v2.py:11490). A return from a sidebar page doesn't roll (v2.py:6885).
  - The picker shuffles the valid random canvases and returns the first that wins its roll, so at most one moment
    fires per render (v2.py:6866-6985).
  - After a hit the place rests 3 renders unless trigger.random_cooldown is set (v2.py:6979-6981, read from the trigger
    at v2.py:15362-15366; engine fixture games_toml_files/engine_random_cooldown_2026_11_12.toml). Every party moment
    and the end set random_cooldown = 0, so a moment at 23:50 never stops the end from firing at 00:10.
  - Once a day: max_triggers_per_day = 1 is counted when a canvas's first screen shows (setup.canTriggerActivity,
    v2.py:5642; setup.markCanvasTriggered on node 0, v2.py:17063-17064). Moments and the dare only run Sat 21:00–00:00,
    so a night can't have two of one across midnight.
  - The speaker guy rides on Dance: setup.checkAndSubstituteCanvas (v2.py:7011) runs at the top of Dance's first
    screen; he is substitution_only, like marco_hips (P56).
  - partied_this_week means what it meant: she has left this week's party. Go home and the end set it. Every party
    button waits on it being false (the random moments and the end don't: walkins.py reads a daily-tick flag there as
    the shared brake, C2187), and the Monday tick unsets it (0_systems_spec.toml:572). Walking out
    by the place's own exit sets nothing (an exit can't set a flag), so she can walk back in that night, which is true.
