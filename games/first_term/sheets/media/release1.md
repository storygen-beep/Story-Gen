## How to read a row
- **where**: `top` = first thing on the screen; `after "…"` = right after that line, on the same screen.
- **kind**:
  - `pic` is a still image.
  - `clip` is animated.
  - `pool` means the block rotates through a folder, one file a visit. Every screen she sees more than once
    gets a pool.
- **tier** (it sets the format):
  - `t0` everyday, still
  - `t3` a look, a towel, cleavage, still
  - `t4` skin, still or clip
  - `t5` sex, clip only
- **One block, one name.** No two blocks share a pool or a file.
- **When the text changes with what she wears** (towel / naked / underwear), each version gets its own block,
  so the picture always matches the words.
