# Location-design note — the skill's "exact-needed locations" rule is WRONG for Vesper

**Status:** game-folder note (LO directive, 2026-06-20). A candidate fix for the skill's
`location-design.md` doctrine later; recorded here in the game folder for now, per LO.

## The critique (LO)
The skill's location discipline — `location-design.md`'s room-content floor ("if you can't name what the
player DOES there, the room doesn't ship") applied as a **hard cut**, plus `step-2b`'s "add zones only where
content lives / size to the cast" — produced a **utilitarian, scene-holder map**: only the exactly-needed
mission locations exist. It does **not** feel like a real, living world. LO rejected the first Vesper map
(two abstract roots, four mission zones) for exactly this.

## The honest nuance (so the note is useful, not just "the rule is wrong")
- **What's RIGHT in the rule:** a *dead room* — an empty clickable location with nothing to do — feels
  *worse* than no room; the engine punishes it. That failure mode is real.
- **What's WRONG:** the rule conflates "no empty rooms" with "no atmospheric/ambient places." It cuts the
  texture that makes a world feel lived-in. A minimal exact-needed map is correct for avoiding dead rooms and
  *wrong* for immersion. "Earns its keep" must count **ambient life**, not only **plot function**.

## The corrected principle (for Vesper — learned from DoL)
A living world = **content density + systems + a real city structure**, NOT a minimal map:
1. **A real city you traverse** — one coherent map (the Tower is a building *in* New Halcyon; leave it → the
   city → the city contains everything; street/district structure, not abstract roots).
2. **People living their own lives** — NPCs on schedules moving through the city, doing things that aren't
   about the player; you *cross* them.
3. **Ambient reactivity** — random street events, the world reacting to dress/place/time; life the player
   didn't trigger.
- **Atmospheric places earn their keep via ambient life / light content** — not cut for lacking a mission.
- **Depth over breadth:** a small, dense, genuinely-alive slice beats a sprawling map of thin places.

## Cost (named honestly)
A living world is a **content expansion** (ambient events + NPC routines + reactivity) over a tight
mission-slice. Deliberate and worth it for a memorable game — not free.

## Action
Design Vesper's map as a **living city, learning from DoL** (street-graph / real-city archetype). Then
consider folding this correction back into the skill's `location-design.md`.
