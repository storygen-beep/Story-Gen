# design-site — CHANGELOG

- 2026-11-27 — Created the skill. `SKILL.md` defines a seven-step guided flow (brief, message, look, build, review, motion, ship) that asks the user a question with a recommended answer at every step, works in Artifacts and the session scratchpad, and writes to the repo only on export (`sites/<slug>/` plus a zip). `references/conversion-rules.md` condenses the build and review rules from `docs/design/web-design-conversion-playbook.md`; `references/artifact-rules.md` lists the Artifact page constraints and this skill's `data-cta` / `data-placeholder` conventions; `references/review.md` holds the three parallel reviewer briefs (design, conversion, usability/accessibility). `scripts/build.py` wraps an Artifact fragment for local preview and exports it as a split site folder with a zip; `scripts/check.cjs` takes phone/tablet/desktop screenshots and measures first-screen button visibility, reading grade, line length, tap targets, overflow and font loading. Roles assigned to the vendored skills: `frontend-design` builds; `copywriting`, `pricing`, `signup`, `awesome-design-skills`, `ui-ux-pro-max` supply material; `impeccable`, `cro`, `web-design-guidelines`, `accessibility-scan` review; `animate`/`choreograph` for motion; `ab-testing` for the test plan. Verified: both scripts run end to end on a sample fragment (preview, check at three widths with Google Fonts loading through the proxy, export with data-URI extraction and zip, exported page re-checked with no console errors); `impeccable detect` and the AccessLint scan commands both ran successfully in this container; every `.claude/skills/...` path named in the skill exists. Not yet verified: a full run of the seven steps with a real brief.
- 2026-11-27 — Added redesign mode. New `scripts/extract.cjs` visits a URL plus up to five useful internal pages (pricing, about, features, FAQ, contact…) and returns only words — headings, body text, button labels, form fields, prices, contact details, structured data, image alt text — and no colours, fonts, CSS, layout or screenshots. `SKILL.md` gains a "Step 1 in redesign mode" section: hard rules that the old site is read only through that script and that nothing visual or structural is carried over; a found / guessed / missing sort with a recorded quote for every found fact; questions for whatever is missing plus traffic source, reason for the redesign and brand elements to keep (default none); and the later-step differences. `brief.json` gains a `source` block; frontmatter description and argument hint updated. Why: LO asked for a mode that takes a real website, ignores its UI/UX completely, and extracts the brief answers from it, asking only when it cannot find them. Verified: `extract.cjs` run against a live marketing site returned four pages with headings, text, prices from the pricing page, a form and structured data, with no errors. Not yet verified: a full redesign run end to end.
