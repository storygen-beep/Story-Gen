# plan — the game plan, then the release's piece list

Stub. Filled in during Phase 3, from `lists/COVERAGE.md`, only as the test game needs it.

**What it is.**

1. **New game: the one-page game plan, first.** Her, the want, the people, the places, the rough arcs, and roughly what each release adds. Show it to LO in bites; record each answer in `NOTES.md`. No release piece list until LO has said yes to the game plan.
2. **Each release: the piece list.** Decide what this release holds and split it into pieces. Release 1 is the skeleton: every person, place, system and the daily loop, each shallow; meters shown, not yet moving. Later releases add depth.

**Reads.** `games/<slug>/STATE.md`, `games/<slug>/NOTES.md`, and LO's answers in chat.

**Writes.** The game plan's decisions in `NOTES.md`, one line each, in LO's words with the date. The release's piece list and its out-of-scope line in `STATE.md`.

**Done when.** LO has said yes to the game plan (new game) and to the piece list, and `STATE.md` ends `Next step: piece — <first piece>`.
