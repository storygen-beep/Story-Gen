## Verdict words

- **keep**: went red on a real bug that no human had found first, and the bug was fixed. Proof cited.
- **built-for**: written after a human had already found the bug, and red only on that same bug. It proves the check can see the bug, but it never found one first. *How built-for counts is LO's call* (see the review).
- **never caught**: searched, and no recorded real red was found.
- **false green**: it passed while the real bug it targets existed. Bug cited.
- **false red**: it went red on fine content and was waived, rewritten or argued away. Waiver cited.
- **unsure**: the evidence is ambiguous. The reason is given. Not guessed.
- A second verdict after `;` (e.g. `keep; also false red`) records a second finding about the same check.
- **kind**: *rule* = a script can decide it exactly · *judgement* = taste or a borrowed threshold, which belongs to the reader, not a gate.
