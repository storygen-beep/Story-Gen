> from the Great Games Study (`~/Documents/Great_Games_Study_20260926/round2/`). Every quote is the
> game's own text, verbatim, in the named passage. **Take the KIND, never an entry.** A pitch that
> restates an entry — the same situation with the same kind of person — is a copy, not a moment.
>
> ⚠️ **Adults only.** Every moment here involves adults, from games that state their characters are
> adults. Never set an idea in a school, or with anyone under 18.

The pitch pack prints one kind's ten (`pitch_pack.py <slug> --kind <kind>`); each Pitcher is given a
different kind (`the-release.md`, "Her moment"). A `why` marked **[my reading]** has no player
comment behind it; the rest cite the player evidence in the study's game files.
