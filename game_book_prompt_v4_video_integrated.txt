## VIDEO DESCRIPTION JSON FORMAT

Video description files are generated by the asset pipeline and contain:

```json

  "clips": [
    {

      "description": "A woman kneels in a kitchen..."  ← AI-generated description

    {
      "id": "e5f6a7b8-c9d0-1234-ef01-345678901234",
      "index": 2,
      "description": "The couple moves to the bedroom..."
    }
  ]

```

CRITICAL: The `id` field contains the ACTUAL UUID that must be used in TOML files.
Do NOT use the `index` number. The UUID enables the game engine to load clips
from the database using: `{ type = "clip", props = { clipId = "uuid-here" } }`

When referencing clips in this book and in session state:
- ALWAYS use the full UUID (e.g., "42c1f739-89df-4196-874a-d57850d72817")
- NEVER use index numbers (e.g., "clip 1", "clip_12")
- The UUID is the permanent identifier that connects book → TOML → database

When the NPC first appears, provide:
- FULL PHYSICAL DESCRIPTION (height, build, eyes, hair, presence, what draws attention)
- How they've CHANGED (if returning scenario) or what STRIKES you

- The FIRST WORDS they speak
- The CHEMISTRY/CONNECTION hint (the moment that signals attraction)

### 3. SITUATION ESTABLISHMENT (Node 3)
Before gameplay begins, player must know:
- What are the STAKES? (wedding, deadline, departure, etc.)
- Who else MATTERS? (fiancée, spouse, family, rival)
- Why are they ALONE together? (what creates the opportunity)
- What is FORBIDDEN about this? (the taboo element)

## TOML GENERATION INSTRUCTIONS

When generating TOML from this book:

1. **Reference the CLIP LIBRARY section** for all integrated videos
   - Use actual UUIDs from the CLIP REGISTRY
   - Format: `{ type = "clip", props = { clipId = "uuid-here" } }`

2. **For integrated clips:**
   ```toml
   [[activity_content.tiers]]
   tier = 6
   narrative = "She drops to her knees..."
   blocks = [
     { type = "clip", props = { clipId = "42c1f739-89df-4196-874a-d57850d72817" } }
   ]
   ```

3. **For external sources (no UUID):**
   ```toml
   [[activity_content.tiers]]
   tier = 1
   narrative = "Casual morning coffee..."
   blocks = [
     { type = "video", props = { file = "activities/kitchen_t1.mp4", description = "Morning coffee chat" } }
   ]
   # Or leave empty for later sourcing
   ```

4. **Verify all UUIDs exist** in the video description JSON before using them

5. **NEVER use index numbers** like "clip_18" - always use the full UUID
```
